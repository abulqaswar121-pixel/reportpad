# NDH eStore

Multi-vendor commerce platform for Najeeb Digital Hub — [estore.ndh.com.ng](https://estore.ndh.com.ng). Built with TanStack Start (v1) + Vite 7 on Supabase.

## Quick start

```bash
npm install
npm run dev   # serves on http://0.0.0.0:5173
```

No environment variables are required to preview: with no Supabase keys the app runs in **demo mode** (sample storefront at `/store/amari-atelier`, demo dashboard data). Connect a real backend by copying `.env.example` and filling in the values.

| Script | Purpose |
| --- | --- |
| `npm run dev` | Dev server (bound to 0.0.0.0 for previews) |
| `npm run build` | Production build |
| `npm run build:dev` | Development-mode build |
| `npm run start` | Preview the production build |
| `npm run typecheck` | `tsc --noEmit` |

## What's inside

- **File-based routing** under `src/routes/` — all routes declare their own `head` metadata. `src/routeTree.gen.ts` is generated by `vite build`; do not edit it by hand.
- **Storefronts** (`/store/$vendorSlug`) with per-vendor `--store-accent` theming, multi-currency pricing (NGN/USD/GBP), region-based shipping, and a WhatsApp order fallback.
- **Checkout** via Paystack (NGN) and Flutterwave (USD/GBP) with checkout tokens, server-side order creation, and payment webhooks.
- **Vendor dashboard** (`/dashboard`) — Products, Orders, Shipping, Payouts, and Meta tabs; **admin** panel at `/admin`.
- **Supabase RPCs** (defined in migrations, called from server functions): `create_storefront_order`, `mark_order_paid`, `vendor_ngn_ledger`, `request_vendor_payout`, `replace_product_variants`, `vendor_transition_order`.
- **Meta Commerce**: catalog feed at `/store/:slug/feeds/catalog/xml` + Conversions API events.
- **AI assistant "Nia"** with commerce prompt shortcuts.

## Brand

Uses the exact NDH master assets (`public/ndh-gateway.png`, `public/ndh-ai-assistant.png`) with the lucide `ShoppingBag` sector. Headings in Space Grotesk, body in DM Sans. Deep Navy `#070F1E` canvas with Electric Cyan `#00E5FF` accents — see `src/styles.css` for the full token set.
